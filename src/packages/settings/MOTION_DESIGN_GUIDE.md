# Motion Design Guide (디자이너용)

`@byuckchon-frontend/settings`의 **motion**은 벽촌 프론트엔드 프로젝트가 공통으로 쓰는 모션 규칙이다. basic-ui의 각 UI에 기본으로 적용되는 모션을 정의해 둔 것으로, 프로젝트 담당자가 적용 여부를 정하되 **기본적으로 사용하는 것을 권장한다**

이 문서는 **디자이너가 읽는 문서**임.

- 지금 제품에 어떤 모션이 어떤 값으로 들어가 있는지 확인하고
- 바꾸고 싶은 게 있을 때 **무엇을, 어떤 이름으로 요청하면 되는지** 알기 위한 문서이다.

> 프론트엔드용 문서는 Motion-Animation 프론트엔드 가이드 로서,
> 이 문서의 클래스 이름은 프론트와 이야기할 때 서로 같은 걸 가리키기 위한 것이라 외울 필요는 없다.

---

## 1. 모션이 동작하는 구조

```
 [토큰]                       [모션 정의]                 [컴포넌트]
 --motion-toast-duration  →  motion-toast           →  ToastMessage
 200ms                       투명도 0 → 1                등장/퇴장에 사용
                             아래에서 8px 올라옴
                             크기 98% → 100%
```

- **토큰**: `-motion-*-duration` 형태의 값. 프로젝트별로 덮어쓸 수 있다. → 디자이너 영역
- **모션 정의**: 어떤 속성이 어디서 어디로 움직이는지. 사내 공통이라 프로젝트마다 바꾸지 않는다. → 프론트 영역
- **컴포넌트**: basic-ui의 Modal, Toast, Dropdown 등. 정의된 모션을 가져다 쓴다.

즉 **"Toast를 조금 더 느리게"** 는 토큰만 바꾸면 되고, **"Toast가 위에서 내려오게"** 는 모션 정의를 바꿔야 하는 일이다

---

## 2. 공통 가속도(easing) 2종

모든 모션은 아래 두 가지 중 하나를 쓴다. 별도 요청이 없으면 전부 `ease-out` 이다.

| 이름 | 토큰                   | 값                                  | 느낌                                                                          |
| ---- | ---------------------- | ----------------------------------- | ----------------------------------------------------------------------------- |
| 기본 | `--motion-ease-out`    | `cubic-bezier(0.16, 1, 0.3, 1)`     | 출발이 빠르고 끝에서 부드럽게 감속. 대부분의 UI 모션                          |
| 탄성 | `--motion-ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 목표 지점을 살짝 지나쳤다가 돌아옴(튕김). 체크 표시처럼 "확인됐다"는 피드백용 |

---

## 3. Figma에서 토큰으로 넘기기 (Tokens Studio)

- color/typography와 **완전히 같은 방식**으로 motion도 관리하고 한 번에 넘길 수 있다. 다만, 아래 이미지처럼 **Other라는 이름에 추가**해야 한다.

### 3-1. 이름 규칙 (가장 중요)

- **토큰 이름은 정해진 변수명 그대로** 써야한다. (`--`까지 포함)
- 또한 값은 단위(ms)없이 숫자 그대로 작성한다.

- 다만 프론트가 `npm run tokens:build`를 돌릴 때, settings에 없는 `-motion-*` 이름이 있으면
  **경고를 띄워 오타를 잡아주기 때문에** 혹시 값이 안 먹으면 프론트에게 이 경고부터 확인해달라고 한다.

### 3-3. 전달 흐름

```
Figma (Tokens Studio)
  → tokens.json export
  → 프론트 저장소 src/tokens.json 에 커밋
  → npm run tokens:build
  → src/tokens.css 자동 생성 (색상 · 타이포 · 모션이 한 번에)
  → 기본값을 덮어씀
```

- 이후 export 과정은 색상, 타이포와 같으니 생략한다. 자세한 내용은 Motion-Animation 프론트엔드 가이드 를 참고한다.
